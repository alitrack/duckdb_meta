# DuckDB Meta Extension

`duckdb_meta` brings **classical meta-analysis** into DuckDB as SQL table
functions — a faithful port of JASP's *Classical Meta Analysis*, which is a thin
wrapper over `metafor::rma.uni` (default estimator REML). No moderator, single
effect-size column.

The port covers the **12 single-column τ² estimators** JASP exposes
(`GENQ`/`GENQM` are deferred — they require the `CompQuadForm` package's
Farebrother computation), plus the overall z-test and per-study forest
weights.

## Functions

| function | signature | returns |
|---|---|---|
| `meta` | `meta(y LIST, se LIST [, method, level, maxiter])` | one row: `method, k, beta, se, ci_lo, ci_hi, z, p, tau2, se_tau2, q, i2, h2` |
| `meta_forest` | `meta_forest(y LIST, se LIST)` | one row per study (missing dropped): `study, y, v, ci_fe_lo, ci_fe_hi, w_fe, ci_re_lo, ci_re_hi, w_re` |

* `y` — effect sizes (e.g. log-odds / mean-difference per study)
* `se` — **standard errors** per study (internally squared to the sampling
  variance `v`); a `NULL`/non-finite study is dropped (JASP's NA handling)
* `method` — `EE | FE | ML | REML | DL | HE | HS | HSk | SJ | EB | PM | PMM`
  (default `REML`)
* `level` — confidence level, default `0.95`
* `maxiter` — Newton iteration cap, default `100`

### Example

```sql
LOAD 'meta_ext.duckdb_extension';

SELECT * FROM meta(
  y  = [0.82, -0.15, 0.45, 1.10, 0.30, -0.60, 0.72, 0.05],
  se = [0.30, 0.22, 0.25, 0.16, 0.19, 0.24, 0.17, 0.28],
  method = 'REML'
);
-- beta  se  tau2  q  i2  h2  k
-- 0.346 0.199 0.2657 49.81 85.17 6.745 8

-- forest plot data (random-effects weights use REML tau2)
SELECT study, y, w_re, ci_re_lo, ci_re_hi FROM meta_forest(
  y  = [0.68, 0.75, 0.52, 0.61, 0.91, 0.44, 0.70, 0.58],
  se = [0.30, 0.26, 0.35, 0.31, 0.22, 0.39, 0.28, 0.33]
) ORDER BY study;
```

## Estimators (metafor `rma.uni`, single column, no moderator)

All share the one-way weighted model `X` = intercept. The projection matrix is
`P = W − WX(X'WX)⁻¹X'W` (with `W = diag(1/(v_i+τ²))`), so `P_ij = w_i·δ_ij −
w_i·w_j/S` and `RSS = Y'PY`. The response is centered on the **unweighted**
mean (metafor's `Ymc`).

* **FE / EE** — fixed / error-of-estimation (τ² = 0).
* **DL** — DerSimonian–Laird method-of-moments.
* **HE** — Hartman–Hopswood.
* **HS / HSk** — Higgins– Thompson; `HSk` uses the small-sample k-corrected form.
* **SJ** — Sidik–Jonkman.
* **ML / REML** — (restricted) maximum likelihood via Newton iteration,
  started from the HE estimate.
* **EB** — empirical Bayes.
* **PM / PMM** — Paule–Mandel; solves `RSS(τ²) = target` by bisection where
  `target = k−p` (PM) or `qchisq(0.5, k−p)` (PMM, median-unbiased).

`I² = 100·τ²/(vt+τ²)`, `H² = τ²/vt + 1` (random) or `Q/(k−p)` (FE), where
`vt = (k−p)/tr(P_FE)`.

## Verification

* `cargo test --offline --lib` — an oracle test drives every (dataset ×
  method) cell in `test/fixtures/meta_ref.csv` (6 datasets × 12 methods)
  against values generated by **R `metafor` 5.2.1**, tolerance 1e-5.
* `test/meta_e2e.sql` — end-to-end through a built `.duckdb_extension` with the
  DuckDB CLI: all 12 estimators' τ² on `d1_small` match the R oracle
  bit-for-bit; REML/PMM β, se, τ², I², H² across all 6 datasets; and forest
  weights/CIs on `d6_forest` (NA `se` dropped → 24 studies) match
  `meta_forest_ref.csv`.

Regenerate fixtures (requires R + `metafor`):
```sh
Rscript test/gen_meta_ref.R   # -> test/fixtures/meta_ref.csv, meta_forest_ref.csv
```

## Build (WSL, offline)

```sh
DUCKDB_EXTENSION_NAME=meta_ext DUCKDB_EXTENSION_MIN_DUCKDB_VERSION=v1.2.0 \
  cargo build --offline
python3 extension-ci-tools/scripts/append_extension_metadata.py \
  -l target/debug/libmeta_ext.so -o build/meta_ext.duckdb_extension \
  -n meta_ext -dv v1.2.0 \
  -evf configure/extension_version.txt -pf configure/platform.txt
duckdb -unsigned -f test/meta_e2e.sql
```

The loadable binary must be named `meta_ext.duckdb_extension` — the CLI derives
the entry symbol `meta_ext_init_c_api` from the **filename**.

## Out of scope (v0.1.0)

`GENQ`/`GENQM`, moderators / subgroup analysis, Knapp–Hartung `t` test
(currently always the z-test), and forest-plot rendering.
